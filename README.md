# StickyCat

A macOS sticky note app with an animated virtual cat built in SwiftUI.

## Stack

- macOS + SwiftUI
- Swift

## Features

- Editable sticky note with customizable background color
- 6 cat breeds: Black, Brown, Orange Tabby, Siamese, Tuxedo, White
- 7 animated states per breed: idle, walk, jump, sleep, meow, pounce, sit
- Spritesheet animation system with per-state frame counts
- Weighted random behavior loop — walking and jumping happen more often
- Cat jumps occasionally when you type
- Breed selector dropdown
- Note color picker with 5 pastel options
